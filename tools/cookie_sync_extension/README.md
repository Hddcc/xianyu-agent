# 闲鱼 Cookie 同步扩展

这是一个只做一件事的 Chrome/Edge Manifest V3 扩展：读取当前浏览器中适用于闲鱼网页接口的 Cookie，并发送到客服服务的同步接口。

## 安装

1. 打开浏览器扩展管理页，开启“开发者模式”。
2. 选择“加载已解压的扩展”，选择当前目录。
3. 打开闲鱼网页并保持登录。
4. 点击扩展图标，填写客服同步接口地址和 `COOKIE_SYNC_TOKEN`，点击“同步当前 Cookie”。

扩展不会把 Cookie 写入文件，也不会把 Cookie 显示在页面上。浏览器会把同步密钥保存在扩展的本地存储中。

同步接口应使用 HTTPS。直接将 HTTP 端口暴露到公网会把登录凭据置于风险中。
