# Cookie 一键同步工具

这个目录包含两个轻量组件：

- `cookie_sync.py`：随客服进程启动的服务器接口，负责鉴权、验证新 Cookie、备份并更新 `.env`，随后触发闲鱼长连接重连。
- `cookie_sync_extension/`：Chrome/Edge 扩展，读取当前浏览器中的闲鱼 Cookie，并在点击一次按钮后上传。

服务器不需要安装浏览器或新增第三方 Python 依赖。同步接口只有在 `.env` 配置了 `COOKIE_SYNC_TOKEN` 时才会启动。生产环境应通过 HTTPS 反向代理访问接口，Compose 默认只将端口绑定到服务器本机的 `127.0.0.1`。

首次使用需要在扩展中填写服务器地址和同步密钥。浏览器会保存这两项；以后保持闲鱼网页版登录，点击“同步当前 Cookie”即可完成验证、更新和客服重连。
